# 数据结构与算法期中笔记

## 第一章 概论

### 数据结构的定义与分类

- 数据结构：**逻辑** + **存储** + **运算**
- 分类
    - 线性结构
        - 线性表（表，栈，队列，串等）
    - 非线性结构
        - 树（二叉树，哈夫曼树，二叉检索树等）
        - 图（有向图，无向图等）
### 一些概念

- 逻辑结构：数据对象及其关系
- 运算：数据操作
- 抽象数据结构：ADT< 数据对象D，数据操作P >
- 存储结构：建立了一种逻辑结构到物理结构的映射，包括逻辑节点映射和逻辑关系映射
> 基本存储映射的方法：顺序、链接、索引、散列

### 时间复杂度分析

- 重要方法
    - 主定理：对于递推式$T(n) = aT(n/b) + f(n)$
        - 如果 $n^{\log_ba} > f(n)$ （渐进意义下），时间复杂度为 $n^{\log_ba}$
        - 如果 $n^{\log_ba} < f(n)$，时间复杂度为 $f(n)$
        - 如果 $n^{\log_ba} = f(n)$，时间复杂度为 $n^{\log_ba}\log{n}$
