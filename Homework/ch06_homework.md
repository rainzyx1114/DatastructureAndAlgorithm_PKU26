### 2 完全 $K$ 叉树的结点数与编号关系

设有一棵高度为 `H` 的完全 `K` 叉树，其中根结点位于第 0 层，最深结点位于第 `H` 层。各结点按层序从 0 开始连续编号，树中共有 `N` 个结点，且 `K >= 2`。

请回答：

1. `N` 的取值范围。
2. 编号为 `n` 的非根结点的父结点编号。
3. 编号为 `n` 的结点的第 `i` 个子结点编号，其中 `i = 1, 2, ..., K`；同时说明该编号何时确实对应树中的结点。
4. 编号为 `n` 的非根结点在什么条件下有右兄弟？若存在，右兄弟的编号是多少？

解：
1. $\frac{k^{H}-1}{k-1}  + 1 \le N \le \frac{k^{H+1}-1}{k-1} $
2. 编号为$\lfloor \frac{n-1}{k} \rfloor$
3. 编号为$nk + i$，当该编号小于$N$时对应
4. 编号为$n + 1$，当$n + 1 < N$且$n mod k \ne 0$时存在

### 3 按规模合并 + 路径压缩的并查集

初始有 12 个元素 `0` 到 `11`，每个元素各自构成一棵独立的树。并查集采用以下规则：

* `union(x, y)` 先对 `x`、`y` 执行带路径压缩的 `find`，再将规模较小的树根挂到规模较大的树根之下。
* 两棵树规模相同时，将 `y` 所在树的根挂到 `x` 所在树的根之下。
* 根结点的父结点是它自身。

依次执行：

```text
union(0, 1)
union(2, 3)
union(4, 5)
union(6, 7)
union(0, 2)
union(4, 6)
union(8, 9)
union(10, 11)
union(8, 10)
find(3)
union(6, 8)
union(3, 5)
find(1)
find(11)
```

请完成下列问题：

1. 写出所有操作完成后的 `parent[0..11]` 数组。注意：只有实际执行过 `find` 的路径会被压缩，不要把所有结点自动改为直接指向最终根。
2. 说明采用"按规模合并"时，为什么树的高度为 $O(\log N)$。

> 并查集练习题：力扣 547. 省份数量。
>
> **M547.省份数量**
>
> https://leetcode.cn/problems/number-of-provinces/

解：
1. [4, 4, 0, 0, 4, 4, 4, 6, 4, 8, 4, 4]
2. 对某个结点而言，它所处的树高度增加，当且仅当它所在的树和规模大于等于它的树联合；从而设高度增加了$d$次，那么它的规模至少为$2^d \le N$，从而树的高度为$O(\log N)$
